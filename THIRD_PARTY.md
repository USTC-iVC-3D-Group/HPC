# Third-party code

Gaussian Splatting/Scaffold-style scene and renderer code retain source headers
and `LICENSE.md`. Their original terms are retained.

The three extension ZIP archives under `submodules/` contain the CUDA extension
sources and bundled license files. `lpipsPyTorch/` is the inherited
evaluation implementation and retains its original attribution.

PyTorch, PyTorch3D, torch-scatter, torchac, NumPy, Pillow, einops and tqdm
are installed separately under their own licenses.
Dataset rights are not transferred with this repository.
